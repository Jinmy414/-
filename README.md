# 罗瓣

罗瓣是一个基于原生 HTML、CSS 和 JavaScript 的静态作品发现社区原型，适合直接部署到 GitHub Pages。

## 本地预览

在此文件夹中启动任意静态服务器即可，例如：

```bash
python -m http.server 4173
```

然后打开 `http://localhost:4173/`。

## 已实现

- 热门高分 / 冷门高分随机推荐
- 作品搜索、类型 / 地区 / 年代 / 最低评分筛选
- 热门优先、高分优先、最新加入排序
- 本地演示注册、登录、退出
- 作品详情、0–10 分（0.5 刻度）评分
- 评论发布、评论点赞和按赞数排序
- 创建作品、编辑自己创建的作品
- 个人主页、三部最爱作品和三条评论展示
- 已导入 Bangumi 公开条目元数据，扩充作品搜索库（动画、书籍、游戏）
- 已导入首页台词表 130 条随机台词，以及动画名称表 307 个动画条目（其中 200 个带有评分数据）
- 筛选支持多条件组合与 0–10 分双端评分范围，个人主页可自行选择最多三部最爱作品和三条展示评论
- 界面采用豆瓣式的低饱和目录布局：深灰工具栏、绿色导航、蓝色链接和橙色评分

当前为纯前端演示，数据写入浏览器 `localStorage`，尚未接入真实后端数据库或第三方登录。

## 数据来源

扩充作品来自 [Bangumi API](https://github.com/bangumi/api) 的公开条目元数据，页面详情保留对应 Bangumi 条目链接。封面图片由 Bangumi 图片服务提供。
